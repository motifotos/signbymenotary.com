# Sign By Me

High-trust landing page for Sign By Me Remote Online Notary.

## Theme switch

Open `script.js` and change `themeVariant`:

- `0` — Atlantic Trust (blue)
- `1` — Heritage Signature (teal + gold)

## Preview status

This presentation build contains clearly labeled sample client stories and AI-generated portraits. It is intentionally set to `noindex, nofollow` until those materials are replaced with verified reviews and real client-approved images.
